# Inventory management independence

Application and technology inventory mutations consume the canonical client management
independence wall under #277. Existing application write contracts and explicit technology
record/revise contracts carry the shared management-mutation marker. The supplemental
authorizer hydrates the owning client's authoritative actual assignment history and denies
a canonical user with any historical Attest assignment, including after closure or a client
personnel/guest membership relink. Draft staff proposals do not create actual history.

Ordinary authorizers remain mandatory: current owning membership, active tenant, affiliation
and the applicable inventory grant still control access. The wall grants no authority.
Other-client Attest history and Advisory history do not block this client's inventory writes.
The same marked request contracts enforce the denial through HTTP and MCP dispatch.

The application boundary covers declaration, revision, retirement, system-instance declaration
and retirement, access-review scope decisions, and import staging/correlation/acceptance/
cancellation. The technology boundary covers record and revise commands for components,
locations, operational processes, information assets and data flows. Internal trusted import
execution and effect commands retain their frozen-plan authority and are not personal
management mutations.

Ordinary inventory reads keep their existing grants, restriction filters and projection
freshness rules; historical Attest history does not deny shared management record reads.
The existing technology scoped-read marker covers only some read families, so a request is
not classified as a write merely because it lacks that marker.

Focused production-composed tests retain synthetic accepted and closed assignment events,
exercise actual inventory create/revise and import-staging dispatch, and preserve existing
records on denial. Allowed client, guest, Advisory and other-client cases retain real writes;
ordinary reads use their real projections. Synthetic internal proofs and ratified rules are
explicit test fixtures, never evidence of real firm designation or professional acceptance.

Workforce, access-review, RBAC and other management consumers remain separately scoped under
#277. Professional acceptance, rule ratification and compartment search/count/export/
notification enforcement remain open; the compound criteria remain open.
